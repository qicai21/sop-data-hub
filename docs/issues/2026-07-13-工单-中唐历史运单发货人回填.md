# 工单：中唐特钢历史运单发货人回填

**创建日期**：2026-07-13  
**范围**：中唐特钢 `2026-01-01` 至 `2026-04-30` 的 `wagon_shipments.shipper_name`

## 现象

4 月中唐发运记录中，大量 `shipper_name` 为空，无法可靠区分盛京颐昇实际发运记录与历史缺字段记录，影响客户委托单及辅助作业结算主体判断。

## 根因

历史回填进入 `wagon_shipments` 时未完整同步 95306 运单的发货人字段；95306 主事实库仍保存该字段。

## 处理原则

1. 以 `ydid` 一对一关联只读 95306 `shipments`。
2. 仅回填本地空值且 95306 发货人非空的记录；不覆盖本地已有值。
3. 覆盖范围为 2026-01-01 至 2026-04-30，不限于 4 月。
4. 执行前备份 `data/sop_agent.db`；执行后记录更新数、仍为空数和不一致数。

## 验证

- [x] 本地非空发货人与 95306 同一 `ydid` 的发货人一致。
- [x] 已有本地非空值未被覆盖。
- [x] 输出各月份回填结果及剩余空值。

## 执行结果

- 执行前备份：`data/backups/sop_agent_before_zhongtang_shipper_backfill_20260713.sqlite3`。
- 通过 `ydid` 精确回填 4,145 条本地空值；未覆盖任何本地已有非空值。
- 覆盖后，2026-01-01 至 2026-04-30 共 6,458 条中唐记录与 95306 发货人字段一致，剩余空值 0 条、不一致 0 条。
