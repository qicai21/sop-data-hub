# 工单：承认车改按铁路日五天有效期统计

- **日期**：2026-07-23
- **状态**：已完成
- **关联工单**：`2026-07-23-工单-货运看板增加项目承认车数量.md`

## 问题

原实现把“当月已批复、尚未制票”的运单全部计为承认车。未制票的过期
运单仍保持 `status_code=22`，因此会在看板中长期累积，明显高于业务早报。

## 业务口径

- 铁路发运日以每日 18:00 为边界；
- 当日早上提报、下午批复的是次一铁路日运单，18:00 后可使用；
- 运单有效截止时间按 `装运日期 + 5 天 18:00` 推算；
- 看板展示的是“预测到次一铁路日 18:00 时仍可使用”的剩余承认车；
- 仍须满足 `status_code=22`、尚未制票，并按项目发站、到站、货物范围隔离。

示例（2026-07-23 18:00 前）：

- 装运日期 2026-07-19：2026-07-24 18:00 到期，不计；
- 装运日期 2026-07-20：2026-07-25 18:00 到期，仍计。

## 验收

1. 统计依据由 `accepted_at` 改为装运日期字段 `loaded_at`。
2. 月初可以继续统计上月尚在五天有效期内的承认车。
3. 18:00 前后铁路日切换正确。
4. 已制票、状态已推进和到预测边界时恰好失效的运单不计。
5. 固定测试覆盖五天边界及铁路日 18:00 换日。

## 完成情况

- 看板统计已从“当月 `accepted_at`”改为装运日期 `loaded_at` 的五天有效期；
- 以 `当前铁路日 + 1 日的 18:00` 为预测边界；
- 装运日期加五天后恰好在预测边界到期的运单不计；
- 支持 `YYYYMMDD` 和 `YYYY-MM-DD` 两种装运日期存储格式；
- 真实库在 2026-07-23 下午验证：四平 57、汐子 109、朝阳西 83、
  新台子 62；数值包含早报之后新批复但尚未制票的运单；
- 回归测试：`38 passed`。
