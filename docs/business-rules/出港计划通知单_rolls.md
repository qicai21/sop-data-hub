# 出港计划通知单 识别规则 (Rolls)

本规则旨在规范“出港计划通知单”的读取、解析与数据录入流程，确保业务数据的准确性和唯一性。

## 必须遵守

1.  **核心字段完整提取**：每一条放货记录必须提取以下字段，不得缺失：
    *   **放货日期**：识别具体的年月日。
    *   **放货序号**：必须将中文序号转换为标准代码（如：“第一次下达” -> `lot01`，“第二次下达” -> `lot02`，以此类推）。
    *   **运输方式**：识别括号内的运输方式（如：铁路、公路）。
    *   **到站**：必须提取明确的到站信息。
    *   **货量**：准确提取吨数，需仔细核对数字位数，严防漏看。
    *   **其他备注**：提取“清底”、“剩余XX吨”等关键补充信息。

2.  **括号内容深度解析**：文中括号 `（ ）` 内部的信息（如：`铁路 草市`）是放货记录中最关键的“运输方式”和“流向”数据，**必须**完整解析，严禁将其作为无用信息忽略。

3.  **车站名称标准化映射**：
    *   输出“到站”字段时，必须检索“收发货单位和车站匹配关系.md”进行映射。
    *   如果文中出现的是单位简称（如：`朝阳钢厂`）或昵称（如：`鑫达`），输出时必须转换为对应的标准车站名称（如：`朝阳西`、`草市`）。

4.  **数据唯一性与查重校验**：
    *   在更新既有记录时，必须以“放货序号”作为主键进行比对。
    *   若序号相同但日期或重量不同，判定为识别错误或数据更新，需在备注中记录异常，**禁止**直接创建重复条目。

5.  **文档类型标准化**：该类文档在处理流程中必须统一表述为“**出港计划通知单**”。

## 绝对禁止

1.  **绝对禁止忽略流向信息**：严禁忽略括号中关于到站、收货人的描述，这是判断货物去向的唯一依据。
2.  **绝对禁止重复录入**：严禁在未经过序号比对的情况下，仅凭识别出的日期不同就直接录入新记录（防止因日期识别错误导致的重复）。
3.  **绝对禁止非标准输出**：在输出到站和单位信息时，绝对禁止使用非标准简称或口头昵称。
4.  **绝对禁止模糊识别货量**：对于数字识别必须具备高置信度，严禁将“10000”识别为“1000”或类似错误。
5.  **绝对禁止丢失业务关键字**：绝对禁止忽略“清底”、“剩余”等对库存和结算有重大影响的业务标记。
