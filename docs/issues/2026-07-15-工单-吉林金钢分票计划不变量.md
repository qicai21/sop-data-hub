# 工单：吉林金钢分票计划不变量

- 日期：2026-07-15
- 状态：待讨论，禁止执行
- 优先级：P1

## 发现

吉林金钢部分 release batch 的 `batch_quantity`、`total_planned_quantity`、`quantity_tons` 与已入库箱次的关系存在不变量风险；在分票、补录、批次关闭时可能出现“已发大于计划”或同一货票跨批次归属不稳定。

## 本轮决定

只保留审计证据和设计议题，不修改分票规则、release batch 数据、批次数量或历史归属。

## 待讨论

1. 哪个字段是批次计划量的唯一业务口径。
2. 货票/箱次、列车事件、计划号之间的归属不变量。
3. 补录、纠错、拆票、关闭批次时应保持的校验与人工确认界面。
4. 迁移前应生成的全量差异报告与可回滚方案。
