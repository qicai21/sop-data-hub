# 工单: 辅助作业记录审核分配表特化

状态：已处理

## 背景

原 `货运记录表` 口径过宽,既包含发运事实审核,又尝试承载后续结算预览,不适合当前业务使用方式。

用户明确新要求:

1. 这张审核表只针对各发运项目的辅助作业费用审核。
2. 主表增加 `费目`、`辅助作业项目`、`单价`、`金额`。
3. `辅助作业项目` 需要支持项目特化配置。九三大豆集装箱当前可选:
   - `清理整备`
   - `粮食专用箱专项检查`
   默认同时选中两项,单价随选择组合自动变化。
4. 删除样张文件。
5. `费用审核目录_货运记录表` 改名为 `辅助作业记录审核分配表`。

## 本次调整

1. 将主 sheet 名称改为 `辅助作业记录审核分配表`。
2. 主表改为辅助作业专用结构:
   - `费目`
   - `辅助作业项目`
   - `结算状态`
   - `合并标识`
   - `调增减数量`
   - `有效数量`
   - `单价`
   - `金额`
3. `辅助作业项目` 使用组合下拉表达多选:
   - 例如九三集装箱可选 `清理整备`、`粮食专用箱专项检查`、`清理整备、粮食专用箱专项检查`
4. `单价` 改为 Excel 公式,按所选辅助作业项目组合自动求和。
5. `金额` 改为 Excel 公式:
   - `结算` => `有效数量 * 单价`
   - `挂起 / 排除` => `0`
6. workbook 仅保留主表和 `口径说明`,不保留 `结算单元预览`。
7. 删除无用样张文件。

## 项目特化口径

当前已内置九三大豆默认辅助作业配置:

- 集装箱:
  - `清理整备` = 40 元/箱
  - `粮食专用箱专项检查` = 80 元/箱
  - 默认值 = `清理整备、粮食专用箱专项检查`
- 散粮车:
  - `散粮车装卸辅助作业服务` = 450 元/车
  - `散粮车车体检查及作业现场检查服务` = 200 元/车
  - 默认值 = 两项同时选中
