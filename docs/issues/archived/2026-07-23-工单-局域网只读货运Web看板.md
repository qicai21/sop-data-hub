# 工单：局域网只读货运 Web 看板

- **日期**：2026-07-23
- **状态**：第一阶段已完成
- **范围**：现有 CLI 货运看板、局域网 HTTP 服务、launchd

## 第一阶段目标

先验证同一局域网内的 Windows 用户能够访问 Mac 上的认证 Web 服务。页面暂时只显示：

```text
你好 sb
```

确认 Windows 端连通后，再单独接入真实货运看板。

## 第一阶段方案

- 新增静态 HTTP 服务，监听 `0.0.0.0:8765`；
- 使用 HTTP Basic Authentication；
- 凭据仅保存到 Git 忽略的 `runtime/dashboard_web_credentials.json`，权限 `0600`；
- 只允许 `10.1.2.0/24` 和本机回环地址访问；
- 不连接业务数据库，不提供数据 API、写入或任务执行入口；
- 通过 `launchd` 常驻并在 Mac 重启后自动恢复。

## Windows 访问

```text
http://10.1.2.193:8765
```

## 验收

1. 未认证访问返回 `401`。
2. 正确账号密码可打开页面并看到“你好 sb”。
3. 非允许网段返回 `403`。
4. `/api/dashboard` 不开放并返回 `404`。
5. launchd 服务正常运行，本机地址和局域网地址均可访问。
6. 登录凭据不进入 Git，文件权限为 `0600`。
