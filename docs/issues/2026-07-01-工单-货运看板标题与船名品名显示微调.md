# 工单：货运看板标题与船名品名显示微调

状态：已处理

## 背景

货运 CLI 看板当前有两处展示问题：

1. 普通货运项目（中唐、吉林金钢、朝钢）只显示船名，用户需要在船名后直接看到货物品名，例如 `船名(麦克粉)`。
2. 九三大豆循环 label 标题行过长，例如包含“九三大豆·锦州港集装箱总池 箱循环 · 现状 ... 箱数=晨报...盘点池 ... 返空/#号列=95306实时”，在看板顶栏压缩后可读性差。

## 目标

- 中唐、吉林金钢、朝钢三个项目的船名列显示为 `船名(货物品名)`。
- 货物品名显示更具体的品名；`铁矿/铁矿粉/矿粉/红土镍矿` 等泛品名让位给 `混合粉/纽曼粉/麦克粉/金布巴粉/印粉` 等具体品名。
- 九三大豆循环标题压缩为：
  `大豆循环现状 <yymmdd HH:MM> | 总箱量: <N> | 循环车组<几>列`
- 只调整看板展示，不改业务数据、流程状态或数据库写入。

## 验收

- `scripts/cli_dashboard.py` 普通货运面板能显示船名和品名。
- `scripts/jiusan_cycle_board.py` 标题不再输出冗长口径说明。
- 看板脚本能正常渲染。
