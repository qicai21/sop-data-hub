# 工单: 费用审核目录与现场确认单母版改版

状态：已处理

## 背景

项目费用与结算流程需要从“系统直接生成对账单”调整为“先生成可人工审核的货运记录表,再按审核结果生成对账单与现场作业确认单”。

新的主流程:

1. 用户提出针对某个项目、某个作业费目制作审核目录。
2. 系统调用 `wagon_shipment / wagon_container_shipment` 数据,生成发运记录。
3. 用户在发运记录中标定:
   - `结算`
   - `挂起`
   - `排除`
   - `合并标识`
   - `调增减数量`
4. 系统根据用户确认结果生成完整对账单与现场作业确认单。

## 范围

本工单先落两个基础能力:

1. 新增“货运记录表”结构与 Excel sheet 写入能力。
2. 调整九三大豆辅助作业现场确认单母版。

## 货运记录表要求

对账单最前面增加 `货运记录表` sheet,字段至少包含:

- `结算状态`: 下拉选项为 `结算 / 挂起 / 排除`
- `合并标识`: 相同标识的记录合并生成一个结算/确认单元
- `调增减数量`: 在原始数量基础上增减,例如 128 箱调增 2 后按 130 箱生成

## 现场确认单改版要求

1. 顶部取消 `数量 / 验箱数量` 行。
2. 取消 `车号/车型` 与 `箱号` label,统一改为 `作业记录`,留空 6 行。
3. `作业单位/班组` 提到 `作业项目` 区域内。
4. 取消 `备注`,作业记录即备注。
5. 底部分隔线下空 1 行后增加 `说明`:
   - 散粮车: 写开头 2 个车号、结尾 2 个车号、车数量。
   - 集装箱: 写审核后的检验数量,并随机给出 2-10 个 7 位伪箱号。

## 验收

- `货运记录表` 可作为 workbook 第一张 sheet 写入。
- `结算状态` 有 Excel 下拉约束。
- `结算 / 挂起 / 排除` 与 `合并标识 / 调增减数量` 可生成结算单元。
- 现场确认单测试锁定新母版口径。
- 临时脚本不进入提交。
