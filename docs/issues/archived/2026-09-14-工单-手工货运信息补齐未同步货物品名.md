# 工单：手工货运信息补齐未同步货物品名

- **日期**：2026-09-14
- **状态**：已完成
- **范围**：`enrich_release_batch`、货运看板货名展示、吉林金钢林加尼 lot04
- **theme**：T5_货运信息完整性

## 现象

林加尼 lot04 已手工确认金布巴粉，但货运看板显示通用品类“铁矿粉”。

## 根因

手工补齐器仅写入 `release_batches.cargo_name_detail`；看板和发运导出优先读取
`cargo_product_name`，导致具体货物品名没有被消费方读取。

## 修复

- 手工补齐时将确认的货物品名同步写入 `cargo_product_name` 与原始
  `cargo_name_detail`。
- 回填既有林加尼 lot04 的 `cargo_product_name=金布巴粉`。
- 加入回归测试，覆盖历史仅有 `cargo_name_detail` 的修补场景。

## 验收

- `make test`：`723 passed`。
- `make smoke-runtime`：通过。
- 看板接口已显示“林加尼(金布巴粉)”。
- 手工补齐后 `cargo_product_name` 与 `cargo_name_detail` 均可追溯。
- 已重启 `dashboard-web`、`live-service`、`text-watch`。
