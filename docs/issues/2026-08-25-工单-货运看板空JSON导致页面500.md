# 工单：货运看板空 JSON 导致页面 500

- 状态：已处理
- 发现日期：2026-08-25
- 影响：看板服务进程和 8765 端口正常，但访问首页时渲染批次失败，返回空白/错误页面。
- 根因：历史 `wagon_shipments.container_batch_map` 存在空字符串。看板 SQL 仅过滤 `IS NOT NULL`，仍将 `''` 传给 `json_each()`，触发 `sqlite3.OperationalError: malformed JSON`。
- 修复：JSON 聚合查询同时排除 `NULL`、空字符串，并使用 `json_valid()` 作为数据边界保护。
- 验收：包含空字符串、NULL、合法 JSON 的混合测试数据时，查询正常返回；实际 8765 页面 GET 返回 200。
