# 工单：累计出港通知单已存在批次误报漏建

- **状态**：已完成
- **项目**：吉林金钢
- **消息**：`wx_2026-09_811`

## 现象

林加尼 2026-09-09 累计出港计划通知单包含 `lot01`、`lot02`、`lot03`。三个批次均已存在，入库幂等返回 0 条新增，但系统仍向“数据单发群”发送“建出 0 批次，疑似漏建”。

## 根因

`create_release_batch` 执行器把所有“0 条新增”统一视为异常，没有区分：

1. 通知单中的批次确实没有建立；
2. 累计通知单中的全部批次已经存在，当前执行只是幂等重放。

## 修复

在发送告警前，按通知单的项目、船名和标准化 lot 序号核对 `release_batches`。全部 lot 已存在时记录为幂等成功，不发送漏建告警；只要仍有任一 lot 缺失，继续保留原告警。

## 验收

- 林加尼 `lot01` 至 `lot03` 全部存在：不告警；
- 缺少最新 `lot03`：仍告警；
- `wx_2026-09_811` 关联至现有林加尼 `lot03`，不再形成待处理项。
