# 工单：Web 货运看板终端框线错位

## 现象

局域网 Web 看板直接渲染 CLI 的 Unicode 框线。在浏览器中，中英文的实际字宽与
终端 cell 宽度不一致，右边框不能与标题、数据行稳定闭合，阅读体验差。

## 根因

`dashboard_web.py` 将 `cli_dashboard.render_once()` 的 ANSI 文本直接放入 `<pre>`。
CLI 按 East Asian Width 计算补空格并绘制 `┌─┐/│/└─┘`，但浏览器字体不遵守该
终端宽度模型。

## 方案

- CLI/tmux 保留原有终端框线，不改变其输出。
- Web 层识别 CLI 的面板框线，转换为语义化 section/header/body。
- CSS 负责统一的外边框；表格文本仍使用等宽字体并可横向滚动。

## 验收

- Web 面板外边框由 CSS 统一绘制，右边框完全闭合。
- 面板标题、颜色和数据内容仍保留。
- CLI 看板输出不变。
- 增加转换单测，并在桌面与窄视口截图核验。
