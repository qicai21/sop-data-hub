# 工单：累计通知单改汽运未回减铁路批次

- **日期**：2026-09-11
- **状态**：已完成
- **范围**：出港计划通知单 / 累计批次 / 运输方式变更

## 现象

朝钢欧律狄克第三次下达铁路计划 `20000吨`，后续同一通知单明确
`10000吨改为汽运`，因此 `lot03` 的铁路净放货量应为 `10000吨`。系统仅阻止
变更说明被误建为新 lot，未将改汽运数量从对应铁路 lot 回减。

## 修复与验收

1. 解析无独立 lot 序号的“原铁路计划 N 吨，其中 M 吨改为汽运”说明。
2. 仅在前文能唯一按原数量命中已解析批次时，将该批调整为 `N-M`；
   无法命中时不新建、不猜测。
3. 欧律狄克 `lot03` 调整为 `10000吨`，三批累计量调整为 `20000吨`，
   重算已发量及剩余量。
4. 增加回归测试，确保同一通知单仍只生成三个 lot，`lot03=10000吨`。

## 完成结果

- 生产库已调整：`lot03=10000吨`，三批累计计划量 `20000吨`。
- `lot03` 已发 `116车 / 7737吨`，剩余 `2263吨`，无未解析车辆。
- `source_json.manual_release_confirmation` 已保存用户确认口径及调整依据。
