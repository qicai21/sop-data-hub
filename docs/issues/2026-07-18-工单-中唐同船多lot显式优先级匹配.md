# 工单：中唐同船多 lot 显式优先级匹配

- **类型**：匹配规则完善 / 数据配置
- **状态**：已处理
- **项目**：中唐特钢

## 需求

宝丽后续装货发运必须优先归入 lot03；lot03 满后再归入 lot04。

## 根因

中唐检装车主链使用 `match_release_batch_by_ship_destination_cargo`。当同船、同到站、同货物存在多个 `loading/enriched` 批次时，该函数一律返回 `multiple_candidates`，没有消费 `release_dispatch_match_rules.priority`。现有规则表虽已包含 priority 字段，但对这条主链没有实际控制力。

## 改动

1. 多候选时读取活跃的 `release_dispatch_match_rules`。
2. 仅当最小 priority 唯一时自动匹配；无规则、同优先级或规则表不可用时，继续 `pending_review`。
3. 宝丽配置：lot03 priority=10，lot04 priority=20；lot03 完成后其规则会失活，后续自然落 lot04。

## 验收

- 有两个开放批次且规则优先级为 10/20 时，检装车匹配 lot03。
- 优先级相同或未配置时，仍返回 `multiple_candidates`。
- 不重跑既有发运链，不重复发送 Excel 或上传门户。
