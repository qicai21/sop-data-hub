# 工单：累计出港通知单跨非 SOP 流向时 lot 序号误推

- **日期**：2026-08-28
- **状态**：待处理
- **范围**：吉林金钢出港计划通知单建批 / `release_batches`
- **theme**：T5_lot_sequence

## 现象

蓝鳍 2026-08-27 出港计划通知单（`wx_2026-08_2485`）备注明确写有
“第十一次下达计划：5000 吨（铁路四平）”。系统却建出 0 个批次；人工补录时若
只按本 SOP 库中现有最高批次 `lot08` 顺延，会错误创建为 `lot09`。

该累计通知单中的 `lot09`、`lot10` 是非四平流向，不属于本 SOP 项目，不能因其未落库
而改变原通知单的批次序号。

## 根因

当前建批/人工补录链没有把通知单备注里的“第 N 次下达计划”作为批次序号权威来源，
而会受本地已建批次集合影响。跨流向、跨运输方式的历史计划被本 SOP 范围过滤后，
造成批次序号出现空洞并使自动推断失真。

## 修复

1. 解析到“第 N 次下达计划”时，使用 `N -> lotNN` 作为批次序号；不依赖本地最大 lot。
2. 只为当前 SOP 目标流向创建批次，但保留原始序号空洞，不补造非 SOP 批次。
3. 对同一通知单重复处理时，按项目、船名、通知日期、原始序号幂等。
4. 当前数据已人工修正：蓝鳍铁路四平 5000 吨为 `lot11`，关联 `wx_2026-08_2485`；
   `lot09`、`lot10` 不在四平 SOP 范围内。

## 验收

- 增加回放 fixture：蓝鳍 2026-08-27 累计通知单包含第 1 至第 11 次，
  其中第 9、10 次不是四平。
- 自动建出且仅建出四平 `lot11`，批次量 5000 吨。
- 重放不重复建批，已有货运字段不被清空。
