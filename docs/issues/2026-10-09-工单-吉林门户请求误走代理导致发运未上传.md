## 现象

`wx_2026-10_884`，代表车 `1514859`）。本地事实、发运 Excel 与微信群发送均完成，

## 根因

`factory_upload` / `factory_verify` 使用 `requests` 默认环境代理。本机代理
`127.0.0.1:7897` 超时后，登录未成功，上传步骤未发出任何请求；任务却在后续步骤后
以失败收口。门户为固定业务地址，应明确直连，不能受桌面代理状态影响。

## 修复与执行

1. 新增统一门户 HTTP 封装，禁用环境代理；登录、上传、反查、编辑、删除全部复用。
2. 增加回归测试，断言门户请求 `trust_env=False`。
3. 先以精确事件 `wx_2026-10_884` 的 54 个 `ydid` 补传；上传前后均按
   `箱号+车号` 做 present + unique 反查，禁止按整批累计数判断。
4. 回填 `portal_id` / `portal_uploaded_at`，更新外部动作与任务状态；不重发已执行的
   Excel 或微信附件。
