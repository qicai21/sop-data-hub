# 工单：中唐德邻惠达未登记导致放货及检装车链未入库

## 状态

已处理。

## 现象

2026-10-03 的中唐特钢正式出港计划通知单已识别为 SOP，船名为“德邻惠达”，
计划量 17,796 吨、到站汐子。但系统没有创建 release batch；随后 2026-10-06
至 2026-10-07 的 53 车、61 车、47 车三列均无法进入标准检装车链。

## 根因

中唐 `project_meta.known_ships` 缺少到港船名“德邻惠达”。该白名单是放货通知
安全建批的前置约束，未知船名只能保留识别结果，不能自动建立批次或授权后续发运。

## 修复

1. 在 `config/project_sops/zhongtang.yaml` 登记“德邻惠达”。
2. 扩展 `test_zhongtang_known_ships_include_new_arrival_vessels` 回归覆盖。
3. 以正式放货通知的 17,796 吨创建 `德邻惠达 lot01`；将人工确认的货运信息
   （进口船名开普游隼、Pb粉、计划号 `90260900128`、合同号
   `PB-QZDW-CFZT-20260922`、商业数量 17,800 吨）精确绑定该批次。
4. 逐列复核 95306：53 车、61 车、47 车。61 车单中 `4898098` 标注“返港扣修”，
   且无对应发运票，按“实装61节”排除。
