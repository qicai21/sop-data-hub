# 工单:九三美国 lot1 历史箱次被完成闸污染

- 日期: 2026-07-13
- 类型: 数据归属 + 发运重量 + 货运看板
- 状态: 已处理

## 现象

货运看板显示美国 `lot01`:

```text
放货 52535 吨 / 已发 121069.2 吨 / 剩余 -68534.2 吨
```

实际美国放货日在 `2026-07-02`,不应包含 6 月 10 日起的和谐1、诚信历史集装箱箱次。

## 根因

2026-07-08 的九三 container reconcile 中:

1. 当前额外源扫描未读取 `Downloads/和谐1货票.xlsx`、`诚信货票.xlsx`、`美国货票.xlsx`;
2. 历史箱次被判为 `NEW_UNATTR`;
3. `gate_finished_ships()` 未区分历史与新货,将已完成船的所有 `NEW_UNATTR` 都移到当时唯一 loading 的美国 `lot01`;
4. 同时写入 `container_loading_notice.source_ref=reconcile`,后续同步按错误台账持续回灌美国。

## 修复方案

1. 九三对账额外源增加 Downloads 的三船货票文件识别。
2. 完成闸仅能移动不早于当前 active batch 放货日的新货,历史箱次不得触发闸迁移。
3. 用三船货票文件重建 `container_loading_notice` 和 `wagon_container_shipments` 分票,保留一票两船的箱级例外。
4. 重算和谐1、诚信、美国 lot01 的批次进度,并增加回归测试。

## 验收

- 美国 lot01 只统计 `2026-07-02` 及之后归美国的箱次;
- 看板不再出现已发超过放货量;
- 历史完成船不会因为当前有新 active lot 而被完成闸迁移。
