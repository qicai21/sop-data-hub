# 工单：中唐宝丽新船名接入

- **日期**：2026-07-03
- **类型**：规则补齐
- **项目**：中唐特钢

状态：已处理
## 背景

系统出现告警：

```text
⚠️ 出港计划通知单建出 0 批次,疑似漏建
船名:宝丽  通知日期:2026年07月03日
(wx_2026-07_13)可能 VL 误读日期/scope 全过滤/已存在,请人工核对
```

排查时同步发现：

- `message_inbox.id=100002732`
- 群：`中唐特钢发运群`
- 文本补充货运信息已明确出现 `船名：宝丽`

`宝丽` 属于中唐新增到港船名，应加入项目已知船名范围。

## 根因

中唐当前船名清单未包含 `宝丽`：

- `config/project_sops/zhongtang.yaml` 的 `known_ships`
- `src/sop_hub/sop/text_router.py` 的 `_ZHONGTANG_SHIP_KEYWORDS`

导致：

- 共享群 / 文本触发场景下，项目推断和 inspection trigger 识别缺少该船名锚点
- 后续同类消息存在漏识别风险

## 处理

1. `config/project_sops/zhongtang.yaml`
   - `known_ships` 新增 `宝丽`
2. `src/sop_hub/sop/text_router.py`
   - `_ZHONGTANG_SHIP_KEYWORDS` 新增 `宝丽`
3. `tests/functional/test_inspection_text_trigger.py`
   - 新增 `宝丽` 文本触发测试
4. 重启 `text-watch`
   - 使新船名识别规则即时生效

## 验收

- 中唐文本如 `汐子铁，宝丽，实装40节` 可路由到 `inspection_text_trigger_flow`
- 后续 `宝丽` 相关共享群/发运群文本不再因未知船名漏识别
- 相关测试通过
