# 工单：货运看板增加项目承认车数量

- **日期**：2026-07-23
- **状态**：已完成
- **范围**：普通货运看板四个 SOP 项目标题、95306 当月订车成功记录

## 业务定义

“承认车”是公司按发运计划向铁路提交申请后，铁路批复的空运单：

- 每日 11:00 前提交申请，通常在 15:00 左右批复；
- 95306 中表现为 `status_code=22`、`status_name=订车成功`；
- 此时 `ticketed_at` 为空，尚无车号、货物、重量等制票信息；
- 装车制票后，同一 `ydid` 状态升级并补齐车号、货物和重量，不再计入承认车；
- 承认车数量按 `COUNT(DISTINCT ydid)`，集装箱项目也不能按箱号计数。

## 展示要求

项目标题由：

```text
吉林金钢(锦州) [jilin_jingang_jinzhou] [F] (3 个 batch)
```

改为：

```text
吉林金钢(锦州) 承认车 212 [F] (3 个 batch)
```

四个 SOP 项目均按各自 YAML 的发站、到站、货物品名映射统计。统计范围为当月、当前仍处于订车成功且尚未制票的运单。95306 常驻同步继续提供状态更新：15:00 左右的新批复进入统计，发车制票后自然退出统计。

## 验收

1. 标题不再显示内部 `project_id`，显示项目级承认车数量。
2. 只统计当月 `status_code=22 AND ticketed_at IS NULL` 的不同 `ydid`。
3. 已制票、其他月份、其他路线和其他货物不计入。
4. 95306 数据库不可用时看板继续运行，承认车显示 `—`。
5. 固定回归测试覆盖计数、项目隔离和标题格式。
