# 工单：吉林收货人系统逐条修改接口

## 背景

吉林金钢海洋征服者 `lot07`、`lot10_a`、`lot10_b` 在收货人系统中的批次归属需要按箱级调整。门户提供：

`POST /prod-api/sales/transportOrder/edit`

该接口要求提交门户返回的完整记录，只覆盖需要修改的字段。不得根据本地字段重新拼装简化 payload，也不得仅凭车号或箱号单独定位。

## 目标

1. 新增受控的逐条修改方法：实时读取门户原记录，以门户 `id` 和“箱号+车号”双重确认唯一记录。
2. 默认 dry-run；真修改必须显式 `apply`。
3. 仅允许覆盖白名单字段；其余门户字段原样回传。
4. 修改后同时反查旧订单和新订单，确认旧键消失、新键唯一存在。
5. 返回修改前后门户 ID、订单号和验证结果，供本地 `portal_id` 与批次归属回填。
