# 工单: 九三散粮辅助作业现场确认单 PDF 小票版固化

状态：已处理
## 背景

九三大豆散粮费用结算中,`aux_bulk_loading` 与 `aux_bulk_inspection` 两个费目需要按列生成现场作业确认单。前期试验过 Word / PDF / TXT 三种形态后,确认采用 PDF 小票版:

- 宽度 8cm
- 每列一页
- 页面高度按内容自动结束
- 车号只展示前 2 个与后 2 个,中间省略
- 签字区域保留足够空白

## 目标

将“生成辅助作业现场确认单”固化为可重复执行脚本,从 `bulk_loading_notice_wagon` 读取散粮列数据并生成 PDF。

## 版式要求

1. PDF 直接生成,不经 Word 中转。
2. 左边距使用小票默认窄边距,不做额外缩进。
3. 字号按 5 号字近似。
4. `作业单位/班组: 优瑞达物流`。
5. `委托方(签字):` 与 `作业方(签字):` 后各保留 3 个空白行。
6. 去掉底部“样张/数据源”行。
7. 页面在 `备注:` 下方分隔线后结束,不保留大段底部留白。

## 实施计划

- 新增可复用模块: `src/sop_hub/fees/jiusan_onsite_receipt.py`
- 新增 CLI 脚本: `scripts/generate_jiusan_onsite_confirm_receipts.py`
- 输出目录默认: `reports/fee_docs/jiusan/onsite_confirm_receipts/`

## 验收

- 可按 `--ship / --date / --track` 筛选生成。
- 每个匹配列生成一页。
- PDF 版式渲染正常,无截断、无大底部留白。
