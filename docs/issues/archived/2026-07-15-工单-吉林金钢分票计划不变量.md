# 工单：吉林金钢分票计划不变量

- 日期：2026-07-15
- 状态：已完成
- 优先级：P1

## 发现

吉林金钢集装箱业务同时写入 `wagon_shipments`（车级旧表）和
`wagon_container_shipments`（箱级表）。人工修补及分票计划执行路径可只更新
其中一表，造成同一 `ydid + 箱号` 落在不同 lot。2026-07-09 马兰希望 47 车
94 箱即出现旧表为 lot04、箱级表仍为 lot03 的事实分叉。

## 本轮决定

1. 吉林金钢后续入库、分票、发运 Excel、收货人上传和统计均以
   `wagon_container_shipments` 为唯一发运事实源；不再为该项目新增或回写
   `wagon_shipments`。
2. 既有 `wagon_shipments` 不删除，冻结为历史审计快照，不参与吉林分票、批次
   关闭、重量统计或对外单据。
3. 分票计划只约束明确配置的 `planned_box_count`，不把吨位字段和箱数强行等同。
4. 用带前置校验、可回滚备份的迁移修复已确认的 2026-07-09 94 箱 lot03/lot04
   错挂；不触发 Excel 重发或收货人重复上传。

## 验收

1. 新吉林发运只新增箱级行；同一 `ydid + box_no` 不允许跨 lot 事实分叉。
2. 分票后 `release_batch_dispatch_plan.allocated_box_count` 由箱级事实重算，
   不再增量漂移。
3. 吉林批次关闭统计不叠加旧车级表与箱级表。
4. 回归测试覆盖多 lot 分票、重复触发幂等、旧表不参与吉林统计，以及本次修复
   的前置不变量。
