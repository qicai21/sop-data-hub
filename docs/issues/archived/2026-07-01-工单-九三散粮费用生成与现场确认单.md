# 工单:九三散粮费用生成与现场确认单

- **类型**:业务功能实现
- **发现日期**:2026-07-01
- **状态**:已处理
- **严重度**:高

## 背景

费用系统第一阶段 schema 已落地。下一阶段需要拿九三大豆散粮车线作为第一条真实业务链验证：

- 费用批次 `fee_batch`
- 费用明细 `fee_record`
- 现场确认单 `doc_instance`

当前九三 route C（新台子散粮车）已经具备：

- `release_batches` 船/lot 事实
- `wagon_shipments` 车级 95306 数据
- `bulk_loading_notice_wagon` 按日按船逐车通知台账

因此可以先实现“按日按列”生成费用批次与现场确认单。

## 本工单范围

1. 在 `jiusan.yaml` 中补 route C 散粮费用配置
2. 落 `fee_item_catalog` 种子能力
3. 按 `bulk_loading_notice_wagon` 的 `notice_date + ship_name + track + lot` 生成 `fee_batch`
4. 生成对应 `fee_batch_member`
5. 生成 route C 费用明细：
   - 运输收入
   - 国铁运费(按 95306 实际票面)
   - 地铁费
   - 轨道衡费
   - 散粮车装卸辅助作业服务
   - 散粮车车体检查及作业现场检查服务
6. 自动生成现场确认单 `doc_instance`

## 当前实现边界

- 现场确认单先生成 `docx`
- `pdf` 暂不接
- `billing_reconciliation` 聚合暂不在本工单处理
