# 工单: 吉林金钢集装箱重量错误取车级表

## 现象

马兰希望 lot4 看板显示 264 箱、已发 11,556.24 吨；按项目约定每箱 32.28 吨，正确应为 8,521.92 吨。

## 根因

吉林金钢的 YAML 使用平铺 `per_wagon: cargo_count * 32.28` 规则。重量计算器把它解释为车级来源 `wagon_shipments`，而该 lot 的车级表有 179 条历史残留记录、箱级表仅有正确的 264 箱 / 132 运单，导致多算 47 车次 × 64.56 吨 = 3,034.32 吨。

## 修复

1. 吉林金钢明确配置为 `container.per_box: 32.28`，来源固定为 `wagon_container_shipments`。
2. 计算器以 `project_meta.is_container_business` 识别集装箱项目，而不依赖缺失的 `transport_mode` 字段。
3. 全量重算吉林金钢各批次重量和剩余量。

## 验收

- lot4 为 264 箱 / 132 ydid / 8,521.92 吨。
- 即使车级表保留 179 条记录，也不得影响集装箱 lot 的重量与实际车次。
